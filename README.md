# Campus Football: Two-Minute Drill

An original browser arcade football game built around final-drive pressure situations.

## Play
Every run starts late in the fourth quarter. Call a play, manage the clock, complete passes, scramble, run after the catch, convert fourth downs, and take the lead before time expires.

## Modes
- Start Drive
- Streak Mode
- Challenge Mode
- Practice
- Local High Scores

## Controls
- WASD / Arrow Keys: move
- Space: snap / dive
- 1–4: throw to receivers A–D
- Shift: sprint
- E: juke / option handoff
- Q: spin / throw away
- P: pause

Touch controls are included for mobile play.

## Privacy
No accounts, cloud saves, multiplayer, chat, analytics, or personal information collection. Progress and records are saved locally in the browser with `localStorage`.

## Originality
All names, fictional teams, presentation, graphics, audio, and gameplay implementation in this project are original. It does not use NFL, NCAA, Madden, Retro Bowl, NFL Blitz, Backyard Football, or other copyrighted game assets.

## Hosting
Designed as a static HTML/CSS/JavaScript site for Render.
